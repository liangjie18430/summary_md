# 为什么不同模型间可以蒸馏
不同的大模型间除了是数据的比例不一致外，底层语言的规范是一致的，还是有规律的，而大模型是从token间的前后共现关系学，所以还是可以蒸馏

# 为什么Next Token Predict就可以学好

虽然词表很大，而且每次的next token看起来是整个空间，如果词表空间大小为S, 预测一句话的长度为m,那么实际上的空间大小为S^m(即整体的组合数).但是前面每个token的Next token实际上可候选的是不多的。长度越长约束会越明显。
